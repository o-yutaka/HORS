# 顧客データ取扱い v0.1

## v1で受け取るデータ
- CSV / ExcelをCSV化した現場イベント
- LINEログのテキスト抜粋
- 写真metadata

## 原則
- 本番顧客データをGitHubへcommitしない
- secrets / credentials / raw customer filesをリポジトリに置かない
- デモは架空データを使う
- 顧客識別子は可能な限り匿名化する
- 診断レポートには「推定値」と「実測値」を明示する

## v1運用
1. 顧客から必要最小限のデータを受領
2. ローカル/管理された作業領域で診断
3. 結果と入力データを分離して保存
4. 顧客返却後、不要なraw dataは削除
5. Before/Afterの集計値だけを営業証拠として保持

## 禁止
- 顧客の秘密情報を学習データとして再利用しない
- 本人の許諾なく個人情報を営業資料へ掲載しない
- 架空のBefore/Afterを作らない
